# 보드레 · 아기의 하루 기록

> **보드레 1.0.0 APK 사용·배포 중단**
> 사용자 기기에서 ‘잠재적으로 유해한 앱 감지됨’ 및 ‘피싱 시도 후에 설치되었습니다’ 경고가 보고됐습니다. 판정 원인은 확인되지 않았습니다. 기존 APK를 실행하거나 재설치하지 말고, 경고를 무시하거나 기기 보안 기능을 끄지 마세요. 현재 배포용 다운로드를 중단했습니다.


8인치 안드로이드 태블릿을 위한 한국어 육아 기록 웹앱입니다. 큰 활동 버튼, 100ml에서 시작하는 5ml 분유량 조절, 날짜별 기록과 7일 리포트를 제공합니다.

## 브라우저 전용 버전

APK를 설치하지 않는 PWA를 준비했습니다. [웹앱 실행·배포 안내](WEBAPP.md)를 참고하세요. 웹 배포 파일에는 네이티브 플러그인 SDK를 포함하지 않으며, 기존 APK 사용·배포 중단은 유지합니다.

## Android APK

설치용 APK를 만들 수 있습니다. 태블릿 설치, 사진 가져오기, 백업과 서명 키 보관은 [ANDROID.md](ANDROID.md)를 참고하세요. 현재 APK 배포는 중단되어 있습니다. 새 Gemini 사진 인식은 별도 서버 연결이 필요합니다.

## 개발

Node.js 24, npm 11을 사용해 검증했습니다.

```sh
cd /workspace/babyapp
npm ci
npm run dev:web -- --port 5173
```

Gemini 사진 인식에는 [Cloudflare Worker](server/README.md) 배포와 서버 비밀값 설정이 필요합니다. 웹 빌드에는 Gemini API 키를 넣지 않습니다.

```sh
npm test
npm run build:web
npx vite preview --host 0.0.0.0 --port 4173
```

프로덕션에서는 `dist`를 HTTPS 정적 호스팅에 배포하세요. HTTPS에서 Android Chrome의 ‘홈 화면에 추가’로 설치할 수 있습니다. 서비스 워커는 프로덕션 빌드에서만 등록됩니다. 최초 접속 후 기본 기록 화면을 오프라인으로 사용할 수 있으며, Gemini 사진 인식은 온라인 연결과 서버 설정이 필요합니다. 카메라 사용과 홈 화면 설치 여부는 실제 기기에서 확인해야 합니다.

## 기록

- 분유: 시작·종료 시간, 먹은 양(ml), 메모. 종료 시간은 선택입니다.
- 배변: 대변과 소변을 각각 기록합니다.
- 비타민 D·유산균: 복용 시간과 메모입니다. 용량을 추천하지 않습니다.
- 수면: 잠든 시간을 저장한 뒤 ‘일어났어요’로 종료합니다. 직접 시작·종료 시간을 입력할 수도 있습니다. 자정을 넘긴 수면은 해당 날짜별로 나눠 합산하며, 진행 중인 수면도 현재 시간까지 합산합니다.
- 기록 목록을 누르면 수정·삭제할 수 있습니다.
- 아기 이름·생일·기록자 이름은 설정에서 입력합니다.

## 종이 기록 가져오기

사진은 설정된 Cloudflare Worker를 거쳐 Google Gemini로 전달합니다. 원문과 불확실한 항목을 확인하고 시간·분유량을 고친 뒤 저장합니다. 일반 기록은 기기에 저장되며 자동 전송하지 않습니다. 손글씨 정확도는 실제 사용자 사진으로 별도 검증해야 합니다.

```text
2026-10-10
분유 08:00 08:20 100ml
소변 09:00
대변 10:30
수면 11:00 12:30
비타민D 13:00
유산균 13:05
```

날짜, 24시간제 시간(`HH:MM`), 분유량(`ml`)을 사용합니다. 날짜가 없으면 화면에서 선택한 날짜가 적용됩니다. 수면 종료 시간이 시작 시간보다 이르면 다음 날로 해석합니다. 사진을 여러 날로 나눠 촬영하면 확인하기 쉽습니다. 미래 시간과 겹치는 수면은 저장하지 않습니다.

## 저장과 한계

기록은 현재 브라우저의 localStorage에 보관합니다. 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 같은 기록을 볼 수 없습니다. 설정에서 JSON 백업을 내보내고 가져올 수 있으며, 가져오기는 기존 기록에 병합합니다. 백업 파일에는 아기 정보와 활동 기록이 포함되므로 보호자가 안전하게 보관해야 합니다. 로그인·클라우드 공유·서버 백업은 구현하지 않았습니다.

## 검증

`npm test`에서 기록 계산, 종이 양식 해석, Gemini 서버 인증·사용 한도·구조화 응답 처리 등을 확인합니다. 브라우저 확인은 모의 Gemini 응답을 사용하며 실제 Google 인식 검증과 구분합니다. 검증 범위와 배포 단계는 [WEBAPP.md](WEBAPP.md)와 [서버 안내](server/README.md)를 참고하세요.
