# 보드레 · 아기의 하루 기록

> **보드레 1.0.0 APK 사용·배포 중단**
> 사용자 기기에서 ‘잠재적으로 유해한 앱 감지됨’ 및 ‘피싱 시도 후에 설치되었습니다’ 경고가 보고됐습니다. 판정 원인은 확인되지 않았습니다. 기존 APK를 실행하거나 재설치하지 말고, 경고를 무시하거나 기기 보안 기능을 끄지 마세요. 현재 배포용 다운로드를 중단했습니다.


8인치 안드로이드 태블릿을 위한 한국어 육아 기록 웹앱입니다. 큰 활동 버튼, 100ml에서 시작하는 5ml 분유량 조절, 날짜별 기록과 7일 리포트를 제공합니다.

## Android APK

설치용 APK를 만들 수 있습니다. 태블릿 설치, 사진 가져오기, 백업과 서명 키 보관은 [ANDROID.md](ANDROID.md)를 참고하세요. APK는 웹 화면과 OCR 파일을 포함하므로 서버 배포 없이 사용합니다.

## 개발

Node.js 24, npm 11을 사용해 검증했습니다.

```sh
cd /workspace/babyapp
npm ci
npm run dev -- --port 5173
```

`npm ci`는 `postinstall`을 통해 로컬 OCR 엔진과 한국어·영어 언어 데이터를 준비합니다. 언어 데이터는 공식 `tesseract-ocr/tessdata_fast`의 고정 커밋에서 TLS 검증을 유지한 채 내려받고 SHA-256을 확인합니다. 설치 시 `registry.npmjs.org`, `raw.githubusercontent.com` 접근과 `curl`이 필요합니다. 생성된 `public/ocr`은 Git에서 제외됩니다. 다시 준비하려면 `npm run prepare:ocr`을 실행하세요.

```sh
npm test
npm run build
npx vite preview --host 0.0.0.0 --port 4173
```

프로덕션에서는 `dist`를 HTTPS 정적 호스팅에 배포하세요. HTTPS에서 Android Chrome의 ‘홈 화면에 추가’로 설치할 수 있습니다. 서비스 워커는 프로덕션 빌드에서만 등록됩니다. 최초 접속 후 기본 기록 화면을 오프라인으로 사용할 수 있으며, OCR 파일은 실제 사용 시 캐시되므로 최초 사진 인식은 온라인 상태에서 진행하세요. 카메라 사용과 홈 화면 설치 여부는 실제 기기에서 확인해야 합니다.

## 기록

- 분유: 시작·종료 시간, 먹은 양(ml), 메모. 종료 시간은 선택입니다.
- 배변: 대변과 소변을 각각 기록합니다.
- 비타민 D·유산균: 복용 시간과 메모입니다. 용량을 추천하지 않습니다.
- 수면: 잠든 시간을 저장한 뒤 ‘일어났어요’로 종료합니다. 직접 시작·종료 시간을 입력할 수도 있습니다. 자정을 넘긴 수면은 해당 날짜별로 나눠 합산하며, 진행 중인 수면도 현재 시간까지 합산합니다.
- 기록 목록을 누르면 수정·삭제할 수 있습니다.
- 아기 이름·생일·기록자 이름은 설정에서 입력합니다.

## 종이 기록 가져오기

사진은 서버에 전송하지 않고 브라우저의 Tesseract OCR로 읽습니다. 한 줄에 하나의 활동을 적고, 읽은 내용을 반드시 확인한 다음 선택하여 저장하세요. 손글씨와 흐린 사진은 잘못 읽거나 누락할 수 있습니다. 인쇄된 한국어 샘플 사진으로 인식 동작을 검증했으며, 실제 시터의 손글씨 정확도는 검증하지 않았습니다. 읽은 글을 직접 고치거나 같은 양식의 텍스트를 붙여 넣을 수 있습니다.

```text
2026-10-10
분유 08:00 08:20 100ml
소변 09:00
대변 10:30
수면 11:00 12:30
비타민D 13:00
유산균 13:05
```

날짜, 24시간제 시간(`HH:MM`), 분유량(`ml`)을 사용합니다. 날짜가 없으면 화면에서 선택한 날짜가 적용됩니다. 수면 종료 시간이 시작 시간보다 이르면 다음 날로 해석합니다. 사진을 여러 날로 나눠 촬영하면 확인하기 쉽습니다. 미래 시간과 겹치는 수면은 저장하지 않습니다.

## 저장과 한계

기록은 현재 브라우저의 localStorage에 보관합니다. 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 같은 기록을 볼 수 없습니다. 설정에서 JSON 백업을 내보내고 가져올 수 있으며, 가져오기는 기존 기록에 병합합니다. 백업 파일에는 아기 정보와 활동 기록이 포함되므로 보호자가 안전하게 보관해야 합니다. 로그인·클라우드 공유·서버 백업은 구현하지 않았습니다.

## 검증

`npm test`에서 자정에 걸친 수면, 진행 중 수면, 날짜별 합계와 종이 양식 해석을 확인합니다. Chromium으로 분유량 조절, 새로고침 후 보존, 배변, 수면 시작·종료, 종이 양식 확인·저장, 7일 리포트, 800/600/390px 화면 및 인쇄된 한국어 샘플 이미지의 OCR을 검증했습니다. 프로덕션 빌드에서는 서비스 워커 등록 후 오프라인 재접속과 새 기록 저장도 확인했습니다. 실제 Android 태블릿에서의 카메라, 설치, 손글씨 인식은 별도 확인이 필요합니다.
